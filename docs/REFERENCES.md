# Sources et inspirations

Consultées le 12 octobre 2026. Les projets cités inspirent l'organisation ;
aucun partenariat ou classement de « meilleurs mods » n'est revendiqué.

- [Simple Voice Chat](https://github.com/henkelmax/simple-voice-chat) : séparation
  du commun et des plateformes, branches par version et tâches de publication.
- [Sodium](https://github.com/CaffeineMC/sodium) : informations d'installation,
  contribution, construction et distinction des builds de développement.
- [Lithium](https://github.com/CaffeineMC/lithium) : frontières de compatibilité,
  configuration et diagnostic documentés.
- [Template Fabric](https://github.com/FabricMC/fabric-example-mod/tree/26.1) :
  Loom non remappant, séparation client/commun et Wrapper Gradle.
- [Fabric pour 26.1](https://fabricmc.net/2026/03/14/261.html) : passage aux noms
  non obfusqués et Java 25 ; ne pas reprendre un squelette Yarn 1.21.
- [Fabric Meta, jeux](https://meta.fabricmc.net/v2/versions/game) et
  [loaders](https://meta.fabricmc.net/v2/versions/loader) : versions consultables
  par les outils de maintenance.
- [Manifeste Mojang](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json) :
  cible `26.4-snapshot-3`, release stable `26.3`, runtime Java 25 pour la cible.
- [Options Loom](https://docs.fabricmc.net/develop/loom/options) : source sets et
  inclusion de dépendances pour conserver un seul JAR joueur.

La conversation de conception fournie par l'auteur confirme la seed commune,
les mondes séparés, les messages, les rencontres et l'inventaire invité verrouillé.
Son dernier choix conserve le spawn original. Le résumé de l'ancien assistant
n'était pas accessible comme texte ; les décisions ci-dessus reposent sur les
messages de l'auteur et sa demande actuelle.
