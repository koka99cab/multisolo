# v0.1 — Connected Solitude

Périmètre fixé par koka99cab le 12 octobre 2026. Implémentation de développement
`0.1.0-dev.5` ; cette page ne constitue pas une annonce de release publique.

| Fonction | Contrat v0.1 |
| --- | --- |
| Seed commune | `0`, expérience `multisolo:origin`, révision **2** |
| Spawn | Minecraft choisit le spawn vanilla ; aucun téléporteur ou offset |
| Règles communes | Survie, difficulté normale verrouillée, cheats désactivés à la création |
| Identité réseau | Clé Ed25519 locale persistante ; identifiant SHA-256 de la clé publique |
| Messages | Panneau vanilla posé, quatre lignes prédéfinies, couleur vanilla, face et XYZ |
| Persistance | Fichiers sur le relais, conservés après redémarrage et jusqu'à suppression |
| Lecture | Copie temporaire du vrai panneau au même XYZ/face, ou menu proche ; rayon 128, 50 résultats |
| Durée de présence | 7 + upvotes − downvotes jours depuis publication, bornés de 1 à 30 ; archive conservée |
| Installation joueur | Un JAR Multisolo dans un profil Fabric |
| Réseau | Consentement explicite, hors ligne par défaut, relais HTTPS configurable |

Le bouton Multisolo est présent dans l'accueil et la pause. Créer l'expérience
produit une nouvelle sauvegarde avec ses métadonnées ; choisir « solo » dans
Minecraft ne convertit jamais un ancien monde. L’option fantôme s’ajoute au menu
vanilla du panneau, uniquement dans ces expériences. Les copies temporaires se
placent dans l'air avec un support valide, sans remplacer les constructions,
et se retirent hors du champ de la caméra. Elles sont en lecture seule et sans
loot. Les blocs d'origine des auteurs restent en place après expiration. Les votes
pour/contre sont manuels et réversibles. Le texte libre partagé, le chat et les
signalements sont exclus : la modération du contenu utilise le catalogue fermé.

La révision 1 utilisait une seed provisoire. Elle n'est pas réécrite. Une
sauvegarde marquée pour une autre version du jeu ou définition est refusée :
la migration devra être explicite et validée avant ouverture.

## Support Minecraft

Objectif final : **Minecraft Java 26.1 et toutes les versions suivantes**.
Pour l'instant : **26.4-snapshot-3**, déjà choisie pour le socle et dernière
snapshot dans le manifeste officiel lors de cette étape. 26.3 est la dernière
stable. Les builds restent ciblés sur une version exacte ; le support ancien
sera ajouté par portages vérifiés, sans promettre un JAR universel.

Les messages de versions différentes restent séparés : seed identique ne
signifie pas génération identique. Cette décision évite d'afficher une
indication au mauvais endroit dans une autre version du monde.

Le profil de cette première alpha accepte Multisolo seul. Les mods et datapacks
supplémentaires devront être évalués avant activation du partage ; les mods de
performance ne sont pas encore annoncés compatibles.

## Conditions avant diffusion

- Réussir les [essais applicables](../TESTING.md), dont sauvegarde/rechargement.
- Tester le JAR distribué sans le classpath de développement.
- Choisir un domaine et déployer le [relais HTTPS](../RELAY.md), puis le tester
  entre deux machines et vérifier sauvegarde/restauration des données.
- Évaluer la charge, les quotas globaux et les abus par identités multiples.
  Le relais actuel convient aux essais contrôlés.

Le VPS OVH est envisagé, aucun service n'a encore été acheté. Le développement
et les essais locaux ne dépendent pas de cet achat. Échos, entraide, autres
seeds et expériences modifiées viennent après cette v0.1.
